## Инструкции по запуску

1. Клонировать репозиторий и переключиться в ветку `HW1`.
2. Установить зависимости:

```bash
npm install
```
3. Запустить:
```bash
npm run dev
```

##
Доработки:
- Анимации: иконки питомцев, изменения показателей питомцев, журнал событий;
- Персистентный слой данных о питомцах: их показатели, а также события в логах.
